# Proyecto Minería de Datos - E0: Comprensión del Negocio

Proyecto integrador de **Minería de Datos** aplicado a la mejora de asistencia del **Estadio Alfredo Harp Helú** (Diablos Rojos del México), siguiendo la metodología **CRISP-DM** (fase E0: Business Understanding).

## Sitio web (GitHub Pages)

**URL pública:** <https://emifigue.github.io/AyMD-/>

La entrega E0 está lista y publicada. El sitio se genera con [Quarto](https://quarto.org/) y se despliega desde la rama `main`, carpeta `/docs` del repositorio.

## Contenido del repositorio

- `index.qmd` — Portada del proyecto.
- `entregas/E0_comprension_negocio/` — Entregables de la fase E0:
  - `bitacora.qmd` — Bitácora de la reunión (simulada) con el stakeholder.
  - `canvas.qmd` — Business Understanding Canvas.
  - `preguntas.qmd` — Preguntas de investigación y técnicas de minería de datos.
  - `criterio_exito.qmd` — KPIs de éxito en términos de negocio.
  - `riesgos_supuestos.qmd` — Riesgos, supuestos y mitigaciones.
  - `uso_ia.qmd` — Documentación del uso de herramientas de IA.
  - `fuentes.qmd` — Fuentes y referencias de la simulación.

## Reproducir el sitio localmente

```bash
quarto render
```

El sitio se genera en la carpeta `docs/`.
